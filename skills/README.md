# Reviewers

Each folder is a skill MD Writer can use as the reviewer (Review ▸ Review…). The app lists every folder here
that has a `SKILL.md`.

- `writing-review`: written for MD Writer.
- `clarity`: `SKILL.md` and `references/` from [addyosmani/clarity](https://github.com/addyosmani/clarity)
  at `e27ceef`, MIT. Its `scripts/` are left out: they back the lint mode, and reviews
  don't give Claude a shell.
- `plain-writing`: from [docwriter-org/plain-writing-skill](https://github.com/docwriter-org/plain-writing-skill)
  at `f0d3630`, MIT.

To update one, copy the same files from a newer commit and update the commit here.
